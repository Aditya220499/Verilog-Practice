#Verilog Practice Repository ->  o 

This repository is a collection of my practice projects in Verilog HDL, aimed at deepening my understanding of digital design concepts and HDL coding practices. I have explored industry-standard tools such as Xilinx Vivado and Intel Quartus, but for day-to-day practice I am using VS Code with Icarus Verilog (Iverilog) because of its lightweight setup and flexibility.

 
#Key Highlights ->  

Every practice session includes file handling, where inputs are read from files and outputs are written back, simulating real-world testbench workflows.
Projects are modular and well-structured, following HDL best practices for readability, scalability, and synthesis-friendliness.
Covers both fundamental building blocks (adders, comparators, multiplexers, encoders/decoders) and gradually moves toward more complex designs.


#Tools & Environment ->   

Icarus Verilog (Iverilog): For simulation and compilation.
VS Code: Lightweight and efficient editor with extensions for Verilog.
Vivado & Quartus: Explored earlier for synthesis and FPGA workflows; will revisit as projects scale to hardware deployment.


#Goals ->  

Practice file handling in Verilog testbenches consistently.
Strengthen understanding of HDL fundamentals through hands-on coding.
Develop a reusable library of digital design modules.
Experiment with parameterization and modular coding styles.
Transition complex designs to FPGA synthesis using Vivado/Quartus.
